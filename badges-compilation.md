## Reflections

1. **Getting Started with TypeScript**: In the process of studying the module, I figured out how to install and configure TS
2. **Declare Variable Types in TypeScript**: In the process of studying the module, I learned what data types are in TS and how to use them
3. **Implement Interfaces in TypeScript**: In the process of studying the module, I became acquainted with the concept of an interface and studied in detail how to use them
4. **Develop Typed Functions in TypeScript**: Typing functions is quite an exciting activity that also allows you to avoid mistakes
5. **Declare and Instantiate Classes in TypeScript**: It turns out that TS also has classes, I learned with interest the features of using classes in website development
6. **Generics in TypeScript**: Generics are perhaps the most difficult part of TS. They allow you not to duplicate code for each data type, but to use universal functions
7. **Work with External Libraries in TypeScript**: A study was made of modules that are very similar to modules in js
8. **Organize Code with Namespaces in TypeScript**: Another way to organize code, it was interesting to learn a similar concept, similar to both modules and classes
